# 📰 News App

A responsive News App built using HTML, CSS, JavaScript, and the NewsData.io API.

## 🚀 Features

* Latest news
* Search news by keyword
* News images
* Article descriptions
* Read More button
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* REST API
* NewsData.io
